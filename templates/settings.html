Box

Developer Console の Platform アプリで、次を済ませてから下の欄へ貼り付けます。

  1. 「構成」のアプリアクセスレベルは「アプリアクセスのみ」のままにする。
  2. 「アプリケーションスコープ」→「コンテンツ操作」で、ファイルとフォルダの読み書きを有効にして「保存」する。
  3. Client ID と Client Secret をコピーする。Enterprise ID は右上のアカウントアイコンからコピーする。

Client Secret は {{ '保存済み' if secret_set else '未設定' }}です。Box 接続は {{ '接続済み' if box_connected else '未接続' }}です。

保存済みの Secret は表示しません。空のまま保存すると、いまの値を維持します。

Developer Console 右上のアカウントアイコンから「Enterprise ID をコピー」できます。右の「アプリの詳細」を下まで開いたプロパティにもあります。

0 はサービスアカウントのルートです。その中に「Zoom」フォルダを作ります。構成の「アプリケーションスコープ」→「コンテンツ操作」で、ファイルとフォルダの読み書きを有効にしてください。
