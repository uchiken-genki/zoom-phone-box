Zoom 側で行う設定

Zoom App Marketplace の Server-to-Server OAuth アプリで、次の順に設定します。Secret Token をこのアプリへ保存してから Validate してください。

  1. Zoom App Marketplace の Develop → Manage から、この連携用のアプリを開く。
  2. Scopes に、下の 5 つを追加する。
  3. Feature に表示される Secret Token をコピーし、設定画面の「Zoom Webhook」に保存する。
  4. 同じ Feature で Event Subscriptions をオンにし、方法は Webhook を選ぶ。Event notification endpoint URL に、下の Webhook URL を入れる。
  5. Validate が成功したら、Add Events で下の 6 件を追加する。受信対象は All users in the account にして保存する。
  6. Activation でアプリを有効化する。有効になったら、この画面の「Zoom を確認」でトークンが取得できる。
  7. ngrok を起動し直して URL が変わったら、endpoint URL を新しい Webhook URL に差し替え、もう一度 Validate する。起動コマンドは zoom_phone_box\start-ngrok.ps1。

Box 側で行う設定

Developer Console の Platform アプリ（Client Credentials Grant）で設定します。ブラウザでログインするリダイレクト URI は使いません。保存先はサービスアカウントの Box です。

  1. Box Developer Console で、この連携用のアプリの「構成」を開く。
  2. アプリアクセスレベルは「アプリアクセスのみ」のままにする。
  3. アプリケーションスコープの「コンテンツ操作」を開き、ファイルとフォルダの読み書きを有効にして、右上の「保存」を押す。
  4. Client ID と Client Secret をコピーする。Enterprise ID は、Developer Console 右上のアカウントアイコンからコピーする。
  5. 3 つの値を設定画面に入力して保存し、「サービスアカウントで接続」を押す。
  6. この画面の「フォルダを作成」を押す。Zoom フォルダは社内のユーザーが開ける共有になる。リンクはホームの「保存先」に出る。
  7. 設定画面の「Box の共有ユーザー」にメールアドレスを入れて「保存して共有」を押す。そのユーザーの「すべてのファイル」に Zoom フォルダが表示される。
